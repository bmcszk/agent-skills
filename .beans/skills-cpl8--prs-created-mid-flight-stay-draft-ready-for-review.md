Standing rule for PR flow: a PR opened while work is still in progress is created as a DRAFT. Flipping it to ready-for-review (non-draft) is the LAST step, taken only when the work is complete, gates are green, and the PR is genuinely ready for the human reviewer's eye - never mid-flight.

## Triage: Standing rule. Destination: git SKILL.md open-real-PRs section (inverts the old flip-immediately rule) plus the description (always-visible law surface). Docs-only; prose gate.
